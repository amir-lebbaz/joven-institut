# JOVEN Institut de Beauté et Soins (Hydra, Alger)

موقع وتطبيق ويب فاخر متكامل مع لوحة إدارة فورية وقاعدة بيانات محلية دائمة SQLite لمعهد **JOVEN** للتجميل والعناية بالسيدات في حيدرة، الجزائر العاصمة.

---

## 🌟 المميزات الرئيسية

### 1. واجهة الزبونة (Luxury Mobile-First Client Landing Page)
- **تصميم سريري راقي (Skin-Clinic Luxury):** متوافق 100% مع الهوية البصرية لمعهد جوفان (ألوان كريم، ذهبي شامبانيا، عنابي العروض، وخطوط Playfair Display و Tajawal).
- **مؤشر أوقات العمل الذكي المباشر:** يحدد تلقائياً هل المعهد مفتوح حالياً في حيدرة وفق التوقيت الرسمي للصالون.
- **تصفية وتصنيف فوري:** تبويبات ذكية للخدمات مع عداد لحظي + شريط بحث فوري بالاسم أو الوصف.
- **حجز مباشر عبر الواتساب بنقرة واحدة:** كل خدمة تحتوي على زر حجز واتساب مجهز تلقائياً باسم الخدمة ومدتها والسعر المحدث من قاعدة البيانات إلى الرقم الرسمي `213781088061`.
- **منشئ الباقات المخصصة (Custom Package Builder):** إمكانية اختيار عدة خدمات وتجميعها في سلة تفاعلية مع حساب المجموع بالدينار الجزائري وحجزها دفعة واحدة عبر الواتساب.
- **معرض أعمال تفاعلي (Portfolio Lightbox):** 6 أعمال حقيقية مع إمكانية تكبير الصور وشعار `"تم التنفيذ في معهد JOVEN - حيدرة"`.
- **آراء Google Maps الموثقة:** تقييم 4.8 / 5 مع أكثر من 264 مراجعة حقيقية.
- **خريطة ومعلومات حيدرة:** ربط مباشر بموقع المعهد في `Chemin de la Madeleine, 27, Hydra, Alger`.

### 2. شريط العرض التجريبي للمالكة (Sticky Pitch Demo Bar)
- مثبت في أعلى الشاشة للانتقال اللحظي بين **واجهة الزبونة** و **لوحة الإدارة** بدون أي تعقيد أو تسجيل خروج.
- **وضع القفل السري للإنتاج:** إمكانية تفعيل القفل برمز PIN (`1234`) لمنع العميلات من الدخول للوحة التحكم أثناء استخدام الموقع.

### 3. لوحة الإدارة الفورية (Admin CMS Price Controller)
- **تعديل الأسعار بنقرة واحدة:** أزرار `[- 500 دج]` و `[+ 500 دج]` لكل خدمة مع حفظ فوري ومباشر في قاعدة البيانات وتنبيه تأكيدي.
- **تفعيل العروض الخاصة (`🔥 عرض خاص`):** زر تفعيل العرض مع حساب السعر المشطوب تلقائياً.
- **إضافة / تعديل / حذف الخدمات:** نماذج سهلة ومرنة لإضافة عروض موسمية أو تعديل الوصف والمدة.
- **إدارة المعرض وتحديث رقم الواتساب:** إمكانية استبدال رقم الهاتف أو إضافة صور جديدة بضغطة زر.
- **تصدير نسخة احتياطية من SQLite:** تحميل ملف `joven.db` في أي وقت بضغطة واحدة.

## 🗄️ قاعدة البيانات المحلية (Persistent SQLite)

الملف مخزن محلياً ودائماً داخل المجلد:
```
data/joven.db
```
- لا يتطلب أي اشتراك سحابي أو مفاتيح API خارجية.
- يبدأ بالتهيئة والتغذية التلقائية بـ 15 خدمة و 6 صور للمعرض و 4 أسئلة شائعة وبيانات التواصل الرسمية.

## 🚀 كيفية التشغيل

### بنقرة واحدة على ويندوز:
فقط اضغطي نقراً مزدوجاً على الملف:
```
تشغيل_الموقع.bat
```
سيقوم بالتحقق من الخادم وفتح الموقع مباشرة في المتصفح على:
`http://localhost:3000`

### عبر الطرفية (Terminal):
```bash
npm start
```
